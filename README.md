# 약국 한영 음성 통역

부산 세미나 참석 약사님용 플러그인 0.4.0-rc.5와 그림 설명서 v10입니다.

## 시작하기

1. ChatGPT에 로그인하고 플러그인 → 추가 → 플러그인 압축 파일 업로드를 누릅니다.
2. 받은 ZIP을 압축 해제하지 않고 선택한 뒤 플러그인 추가 → 플러그인 설치를 누릅니다.
3. 약국 한영 통역 → 채팅에서 사용해 보기를 누르고 “약국 통역 시작해 줘”를 보냅니다.
4. 같은 대화의 **파형 버튼**을 눌러 실시간 음성을 켜고 말합니다. 옆 마이크는 받아쓰기입니다.

영어 손님 말은 한국어로, 한국어 약사 말은 영어로 통역합니다. 번역을 듣고 번갈아 답하세요. 정해진 첫 문장이나 상담 순서는 없습니다. 시작문 파일을 복사하거나 새 대화로 옮기지 않습니다.

## 제공 규칙

- 화자, 부정, 수량, 기간을 유지합니다.
- 못 들으면 말한 언어로 짧게 되묻습니다.
- 말하지 않은 조언·진단·약 추천을 보태지 않습니다.
- 매 발언에 검색·도구·파일·별도 작업을 붙이지 않습니다.
- 대화를 별도 파일로 자동 저장하지 않습니다. 앱 채팅 기록은 남을 수 있습니다.

## 다른 언어

영어는 제공본을 사용합니다. 베트남어 등 다른 언어는 설명서 마지막의 직접 만들기 실습으로 만들어 봅니다. Codex는 이 추가 실습에서 사용하며, 만든 언어의 실제 음성 시험이 필요합니다. 식약처 조회는 별도 실습입니다.

## 확인 범위

수정 버전 업로드, 같은 대화의 시작 응답, 가상 알레르기 문장의 한영 양방향 텍스트 통역, 같은 대화에서 음성 화면 열기·종료를 확인했습니다. 실제 번역 음성·소음 속 인식·음성 응답 시간과 Windows 설치는 이번에 검증하지 않았습니다. 이전 버전의 Work 음성에서 지연이 관찰됐으므로 새 버전에서도 낮은 지연을 보장하지 않습니다.

설치와 음성 메뉴는 계정·앱·요금제·조직 설정에 따라 다릅니다. 메뉴가 없으면 문의하세요.
